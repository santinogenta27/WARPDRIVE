# Exchanges

Size exchanges are free within 30 days of delivery. The item has to be unworn, unwashed and have its original tags.

Our assistant can start a size exchange for you: we reserve the new size and email you a prepaid return label. We ship the new size as soon as the carrier scans your return, so you don't have to wait for it to reach our warehouse.

You can also exchange an item for a different color or a different product. If the new item costs the same, it's free. If it costs more, you pay the difference; if it costs less, we refund the difference.

If the size or color you want is out of stock, we can refund the item instead.

Each item can be exchanged once. Final sale items can't be exchanged.
