# Privacidad de datos

Usamos tus datos personales solo para procesar tus compras, envíos y consultas, según la Ley 25.326 de Protección de Datos Personales.

Nunca compartimos datos de un pedido con alguien que no sea el titular. Para ver datos de tu pedido verificamos que el mensaje venga del teléfono o email registrado en la compra.

Podés pedir el acceso, la corrección o la eliminación de tus datos escribiendo a privacidad@acmestore.example.
