Demo de Enterprise Data AI

Acme Store es una tienda ficticia. El asistente usa el mismo agente, las mismas reglas y la misma auditoría que por WhatsApp.

  • Preguntá por horarios, cuotas, envíos, cambios o devoluciones.
  • Para ver un pedido, escribí «¿Dónde está mi pedido 1001?» y verificá tu identidad con lucia@example.com. En esta demo no se envían emails: el código aparece en la consola del servidor.
  • Cada conversación tiene hasta 20 mensajes, y hay un límite de uso diario por conexión.
